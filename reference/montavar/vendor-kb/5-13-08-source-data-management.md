# 5.13.08 Source Data Management
URL: https://websonik.com/kennisbank/5-13-08-source-data-management/ — Updated 22-06-2026
Maintain dropdown values of WPS Designer and compatibility rules. Access: Source Data button on WPS list or standalone page. Tabs: Materials (base/filler material types, P-numbers); Weld Processes (ISO/AWS codes); Weld Positions (PA, PC, 1G...); Joint Types (butt, fillet...); Consumable Brands; Wire Types (filler wire classes); Shielding Gas (types, compositions); Tungsten (electrode types); Compatibility Rules. Each tab: Add button, data table with edit/delete per row, Search. Compatibility rules restrict combinations of materials/processes/positions/joints; managed per Rule Set with priority and operators (always, equals, contains, etc.). Example add weld position: Source Data -> Weld Positions -> + Add Weld Position -> Position Code and descriptions (EN/NL) -> Save; appears in Technique tab dropdown.
