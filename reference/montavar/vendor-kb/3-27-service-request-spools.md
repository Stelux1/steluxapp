# 3.27 Service request (spools)
URL: https://websonik.com/kennisbank/3-27-service-request-spools/
Last updated 12-06-2026

## Text
- Overview of the current location of all spools. From this page you create service requests for service companies and link spools to a laydown area. Use the filter to narrow the selection, then select spools to use for services or for moving to a laydown. While selecting, option buttons appear to choose between a service request and a move to laydown.
- **Service request**: select a company for services and enter extra info if needed; click "Bevestigen" (Confirm) to create a PDF with all details.
- **Move to laydown**: choose from the dropdown and click "Confirm".
