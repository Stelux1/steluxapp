# 5.34 Pre-HT/PWHT request manager
URL: https://websonik.com/kennisbank/5-34-pre-ht-pwht-request-manager/ — Updated 28-01-2025
Collecting page of all welds in a project still needing heat treatment; mass requests for pre-heat treatment and post weld heat treatment. Pre-HT (pre-heat treatment): heating material to a temperature to burn off contamination (as the page puts it). PWHT: after welding, relieves stresses. Requests for Pre-HT same window as PWHT; results entry same. Mass requests for Pre-HT and PWHT, based on mass NDT request. Request report redesigned like NDT request reports.
How: open weld record or mass edit welds; tick Pre-HT and/or PWHT in respective columns. Create request: individually via printer icon next to a weld; or mass: menu Options -> 'Generate Pre-HT/PWHT Mass request' (all treatments within an isometric). Request manager from main menu: select welds, 'Generate Mass Pre-HT/PWHT request'.
Columns of the manager: 1 Project (e.g. "Project 01"); 2 Isometric (e.g. 0004); 3 Weld no. (e.g. 005); 4 Type (weld type); 5 Welder (welder id e.g. 1111, 390); 6 PWHT (Yes/No); 7 Ind.No. (ID of first material, e.g. 0001); 8 Chg.No. (heat/change no. of first material, e.g. 1111); 9 Material 1 (e.g. "A234 Gr WPB | EXISTING"); 10 Ind.No. (material 2); 11 Chg.No. (material 2); 12 Material 2 (usually same as material 1); 13 Proces (e.g. 141 = TIG); 14 WPS (e.g. "141-ISO-8.1 BW 48,3-10,1 t=3,0-20,2 Branch").
PWHT cell: "Yes" red -> after request executed and docs uploaded turns green; page icon next to Yes opens archived PWHT requests (red or green); no icon until data has been entered and a request submitted; print icon next to "No" creates and prints a PWHT request.
