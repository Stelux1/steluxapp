# 5.13.13 Best Practices
URL: https://websonik.com/kennisbank/5-13-13-best-practices/ — Updated 22-06-2026
Use master templates and deploy via Use for project; pre-fill from PQR; define approval steps early; no edits after signing; maintain source data centrally; review compatibility rules when adding materials/processes; use revisions not direct edits; verify PDF before final approval; check History tab for audits; restrict Delete to coordinators (drafts only).
