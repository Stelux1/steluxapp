# 5.02 Project sites
URL: https://websonik.com/kennisbank/5-02-project-sites/ — Updated 06-03-2026

Equivalent to "3.02 Project sites" of MTOPilot and "4.01 Het aanmaken van een project" of EstPilot. A project can be standalone or a collection of small projects/repairs at a fixed location. New: button **Add project site**, fill fields.

Project settings:
1. **Mandatory fields** (configurable per project site): when creating a weld record, fields Weld type (Lastype), WPS number, Weld date (Lasdatum), Diameter, Batch/heat number (Chargenummer) are mandatory. For material certification records: Material type, Schedule (Schema), Certificate type are marked essential. Tip: fields not filled in get a red marking.
2. **WPS validation**: welders can only be assigned to a weld record if their qualifications match the required WPS. Requires complete and correct data for it to work.
3. **Archived projects**: archiving keeps active list tidy; archived sites reachable via button **Show Archived Sites**, can be restored.
4. **Material management display setting**: toggle of the material indicator in isometrics: when checked, the indicator lights up as soon as materials have been added to an isometric; when unchecked, the indicator lights up when a pick list has been created.

**Document settings** tab: change application-standard document numbers / signature field names to company standard:
1. Subcontractor QA/QC, Subcontractor construction, Main user interface, Contractor QA/QC, Contractor construction, NoBo: filling these changes labels of the signature fields in the **Pressure test plan (Druktestplan)**.
2. Doc. Nr. & Rev. Nr. and procedure number (VT report): sets default values of the VT (visual) report.
3. Doc. Nr. & Rev. Nr. and procedure number (LISL (GU) & LISL (MV) report): sets defaults of LISL (GU) and LISL (MV) reports.
Update 05-03-2026: copying settings from one project site to a new site extended with extra options (list to grow).
