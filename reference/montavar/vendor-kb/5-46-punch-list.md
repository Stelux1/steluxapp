# 5.46 Punch list
URL: https://websonik.com/kennisbank/5-46-punch-list/ — Updated 26-02-2024
Punching a system is done several times: **pre-Punch and Punch**. 'Add item' adds a punch item with attachment (e.g. photo in PDF); several attachments possible. Also use 'Add item' to record that a punch went well with no punch items. 'Open' generates an overview of punch items. Isometric name is clickable (opens new tab). New: select several items in 'Open punch items' and click **'Mark as finished'** to report them done at once. Text does not describe types A/B/C/D. Screenshots: Afbeelding155, 156.

## Screenshot findings (from screenshot)
- **Punch lists page** (menu item, title "Punch lists"): status dropdown button (current value "Open") with options **Open, Finished, Passed, Removed, All**; buttons Print, "+ Add item", refresh; table toolbar CSV and Excel export (small buttons), Search, page size (20). Columns: #, Project, Isometric (clickable link, red-outlined in the screenshot = the new link feature), Type (letters seen: A, B, C), Description (e.g. "PTC-204: Wrong support number", "Guides missing", "Valve missing", "Label code missing", "Coupling is not tight"), Due date, Contractor (e.g. "Ballast-Nedam Industriebouw"), Punch (value "Pre-punch" or "Punch"), Document ("Download" link), Status (Open / Finished), Options (button "Mark as finished", delete, pencil, checkbox for bulk). Bulk: tick several rows and press top button **"Set as finished"** (screenshot 4, red-outlined). Count example "1 - 20 / 1,553".
- **Punch Lists dialog from an isometric/system** (image 1): tabs "Punch list", "Passed Pre-punch", "Passed Punch"; left form: Project (dropdown), ISO (dropdown "- Project related, not iso -" meaning an item can relate to the whole project/system or to one isometric), Type (dropdown showing "A - Prio 1" style values), File (Choose file), Description, Due date, Contractor (default company), Reported date, Reported by, radio Pre-punch / Punch, button Add. Table rows can show "Finished" (tick) or button "Mark as finished".
- Type letters and their blocking effect (A/B/C/D) are not explained in the knowledge base; only the dropdown label "A - Prio 1" and the existence of types A, B, C (as column values) are visible.
