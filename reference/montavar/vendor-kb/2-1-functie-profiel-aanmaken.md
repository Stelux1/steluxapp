# 2.01 Functie profiel aanmaken (Create a function profile)
URL: https://websonik.com/kennisbank/2-1-functie-profiel-aanmaken/ — Updated 12-06-2026

- Admin of Websonik apps can give each user tailor-made access: for each project and each user a set of rights depending on tasks.
- Log in to any of the applications, choose any project, go to menu **Profiles** to manage access rights. You can edit existing profiles, grant/remove rights, create new profiles. New profile: button **Add profile**.
- An application administrator can create unlimited profiles and assign them per application per user. A user can have different rights on project A than on project B.
- Screenshot captions: "Rechten selectie kaart" (rights selection card). Screens show the profile list and the rights matrix (see appended notes if any).

## Screenshot findings (from screenshot)
- Menu path: hamburger menu -> tools icon -> panel **"System"** containing: Company data, Change password, Change theme, User accounts, **Profiles** (underlined in red). (Shown in the MTOPilot orange header; same System menu in WeldPilot.)
- **Profiles list**: toolbar CSV / Excel / print, Search, button **"+ Add profile"**; column Name with Options (edit pencil, delete trash). Example profile names (10): QAQC 01, Workpreparator 01, QAQC 02, Workpreparator 02, Client 01, Site manager, Delete disabled, Print and export/import disabled, Dashboard view, Full rights.
- **Add profile / Edit profile dialog**: fields Profile (name) and Description; a "Select all" row; then a matrix grouped per application (coloured app icon in column "App"), column "Name" = screen/function (e.g. Factors, Dashboard - EST Pilot, Unit Rates, Unit Rates Groups, Unit Rates Subgroups, Project site Factors, Tariffs, Calculation analyses, Calculation, Price list archive, Service companies, Service requests - Archive, ...) and **seven permission columns** (icon headers): view (eye), add (+), edit (pencil), delete (trash), a download/import-type icon, an upload/export-type icon, print (printer). Cells are checkboxes where the right exists for that screen and a dot where not applicable. Buttons Save / Cancel at the bottom. Resolution too low to list the WeldPilot rows individually.
