# 5.271 Project IRN
URL: https://websonik.com/kennisbank/5-27-1-project-irn/ — Updated 01-05-2025
IRN = Intern Registratie Nummer (internal registration number) for isometric drawings. Choice: automatic generation (unique series per project, auto numbering) or manual entry (field editable). Existing project locations with manual IRN keep manual; no auto numbering; IRN must be entered for each new isometric. New locations without IRN can activate automatic: unique letter series per project (e.g. AAAA) and new isometrics get AAAA0001, AAAA0002, AAAA0003... Activation: open project location, click a project, menu Options, enable 'Automatically fill IRN numbers in'. Then a unique letter series (e.g. AABC) is reserved; each new isometric gets the next IRN in order of creation (ID number); IRN field is no longer editable.
