# 5.13.03 WPS List Overview
URL: https://websonik.com/kennisbank/5-13-03-wps-list-overview/ — Updated 22-06-2026
Central registry of all WPS. Columns: WPS Number (unique; master templates show a Master badge), Revision (Rev 0, Rev 1...), Project, Status (Draft, Review, Approved, Superseded, Archived), Created By / Date, Updated Date, Options.
Status badges: Draft grey = editable, not submitted; Review yellow = submitted, awaiting signatures/approval; Approved green = final, read-only, official PDF available; Superseded = replaced by newer revision; Archived = closed.
Option buttons (visibility): Edit pencil (always, or View if read-only); View PDF (Approved + Export right; opens official PDF in new tab); Create Revision (Approved + Insert); Clone as Draft (not archived + Insert); Use for project (share icon; approved master + Insert); Archive (Approved + Edit); Delete trash (Draft + Delete).
Top bar: Create New WPS; Source Data (toggle embedded panel); Status filter; Project filter; Search (quick search across columns).
Find a WPS: set filters, type in Search, click Edit or WPS number link. Screenshots: list; status filter dropdown.
