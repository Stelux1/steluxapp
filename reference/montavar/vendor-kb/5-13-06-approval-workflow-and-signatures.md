# 5.13.06 Approval Workflow and Signatures
URL: https://websonik.com/kennisbank/5-13-06-approval-workflow-and-signatures/ — Updated 22-06-2026
Workflow: Draft -> (Submit for Review) -> Review -> (all steps signed) -> Final Approve -> Approved.
Approvals tab columns: Step (order and role: Manufacturer, Customer, Third party); Assigned to (user or external signatory); Status (Pending / Approved / Rejected); Actions (Sign digitally, Send invitation, Reject).
Digital signature modal: fields Saved signature (pre-stored from profile, opt), Draw signature (canvas; required if not using saved), Comment (opt). Buttons: Use this signature, Clear, Cancel, Sign. Steps: open WPS in Review, Approvals tab, Sign digitally on your step, use saved or draw, optional comment, Sign; when all signed Actions -> Final Approve WPS. Changing content after a signature invalidates signatures and requires re-signing.
