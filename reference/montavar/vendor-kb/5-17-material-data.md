# 5.17 Weld diameters (slug material-data)
URL: https://websonik.com/kennisbank/5-17-material-data/ — Updated 12-06-2026
Auxiliary table with diameters and circumference in millimetres; used to compute welded diameters and weld-defect (repair) percentages, e.g. to check a weld meets spec. One screenshot (Afbeelding111): the table (diameter / circumference columns, from caption).
