# 4.13 Statuses (ESTPilot section; read because the task asked for it)
URL: https://websonik.com/kennisbank/4-13-statuses/
Last updated 03-09-2024

## Text
- Statuses can be given to created calculations for a clear overview. There are four default statuses in the application. To add new ones click "Voeg status toe" (Add status).

## Screenshot (from screenshot)
- ESTPilot (yellow top bar) page "Statuses" with button "+ Add status", CSV/Excel/print, search. Column "Status" with a colour square, plus Options (edit, delete). The four defaults: Approve (green), Cancel (light blue), On hold (dark blue), Reject (red). Footer 1 - 4 / 4.
- These are calculation statuses of ESTPilot, not MTO isometric statuses.
