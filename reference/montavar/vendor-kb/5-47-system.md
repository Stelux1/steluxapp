# 5.47 System
URL: https://websonik.com/kennisbank/5-47-system/ — Updated 03-09-2024
Menu item 'System': adjustments for user data and usability. Users with full rights add, change, activate/deactivate application users and assign rights; key-users assign, edit or add profiles. Each user can change the theme (default colourful system theme -> 'Pro Suite' theme). Two-step verification can only be switched on/off by the global admin (Websonik) in consultation with the company; turning off is the customer's security risk. Editing 'Company data' only for Websonik Administrator (via helpdesk ticket). 10 screenshots (system menu, users, profiles; Pro Suite theme).
