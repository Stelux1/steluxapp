# 5.08 Welder
URL: https://websonik.com/kennisbank/5-08-welder/ — Updated 16-04-2025
- 'Lassersbestand' (welder file): list of (in)active welders incl. their welding certifications and summaries. Shows welders assigned to the current project plus welders usable on all project sites. Dropdown 'All' shows the full file.
- 'Add Welder' adds; 'Edit' edits personal data.
- Field **'Active on projects'** (multi-select): set a welder active on several specific projects at once.
- Qualifications: one welder qualification can be linked to several WPS in one record: in the welder overview click the certifications icon; when editing/adding a qualification the field **WPS** accepts multiple values.
- Page icon: further edit, add certificates or a weld summary. Give an **expiry date** so the app warns in time that a renewal must be planned. Notifications of expired documents can be switched off per document via the triangle next to the document (in welder overview -> page icon).
- Deactivated welders are hidden; show with 'Show inactive'; also applies to deleted welders.
- 10 screenshots (welder list, edit form with qualification multi-WPS; see appended notes).
