# 5.13.10 Administration and Permissions
URL: https://websonik.com/kennisbank/5-13-10-administration-and-permissions/ — Updated 22-06-2026
System -> System settings -> "Enable WPS Designer" must be checked. Rights on System -> Profiles -> [Profile] -> WPS Designer: s Show, i Insert, e Edit, d Delete, m Approve, x Export. Users can store a default signature under System -> Signatures.
