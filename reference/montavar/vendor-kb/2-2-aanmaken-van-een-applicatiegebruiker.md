# 2.02 Aanmaken van een applicatiegebruiker (Create an application user)
URL: https://websonik.com/kennisbank/2-2-aanmaken-van-een-applicatiegebruiker/ — Updated 12-06-2026

Steps: menu **User accounts** -> **Add User**. Fill required fields: user name, e-mail address, password. For each application (e.g. MTOPilot, ESTPilot, etc.) choose which rights (profile) the user gets; can be per project or for all projects in one go. Click **Save**.
Screenshot caption: example where user "Nikola" has access in two projects, profile "Werkvoorbereider 01" in one project and "Werkvoorbereider 02" in the other.

## Screenshot findings (from screenshot)
- **User accounts list**: toolbar CSV / Excel / print, Search, button **"+ Add User"**; columns Username (green dot = active, red dot = deactivated), Name, Phone, then one column per application **MTOPilot, ESTPilot, WeldPilot, TeamPilot, ToolPilot** each showing green tick "On" or red cross "Off", Options (edit pencil, delete trash).
- **Edit user dialog**: left: Username, Password (masked), Name, Address, Email address, Phone, checkbox "Deactivate user". Right: one tab per application (MTOPilot, ESTPilot, WeldPilot, TeamPilot, ToolPilot); in a tab: checkbox **Enabled**; dropdown **Access** (e.g. "Specific project site(s)", other value = all project sites); list "Home location" of project sites each with a checkbox (access to that site) and a profile dropdown (e.g. "Workpreparator 01", "Workpreparator 02") — profile is chosen per project site per application. Example: Test Projects 2019 ticked with Workpreparator 02; "I.012900.01 N2 installation extension Zuidbroek" ticked with Workpreparator 01; other sites unticked. Buttons Update / Cancel.
