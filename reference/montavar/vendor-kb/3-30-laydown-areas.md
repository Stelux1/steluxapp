# 3.30 Laydown areas
URL: https://websonik.com/kennisbank/3-30-laydown-areas/
Last updated 12-06-2026

## Text
- Create new laydown areas with the button "Voeg laydown toe" (Add laydown). Click the name of an area to see what is on it. Inside an area the button "Geschiedenis" (History) shows which spools were on this area in the past.

## Screenshot (from screenshot, composite)
