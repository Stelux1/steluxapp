# 5.27 Projects
URL: https://websonik.com/kennisbank/5-27-projects/ — Updated 12-06-2026
Refers to chapter 3.21 for creating/importing project data. Top menu: 'Export naar Excel'; 'Options (With selected items)' (select items first): 'Delete selected project' (deletes selected projects, isometrics, data and documents), 'Edit projects (Mass edit)', 'Generate multiple Project books' (project books for all isometrics; >10 isometrics with docs can take 15+ min; files >500 pages may overload the work computer's memory).
Side menu icons (left to right): see which isometrics are in a project/operational system; Printer = print an index of material certificates for all isometrics in project/system; make an isobook (work folder) by choosing which documents to include for all isometrics; open punch list for the project/system (pre-punch and punch); add/change info of a project/operational system; delete project/system and all content (in all applications). ISO book generation can take ~15 min.
Restore deleted projects: users with 'full access': Projects overview -> Options -> 'Show deleted projects' -> reset icon.
Improved ISOBook: per project site customise document list: Edit Project Site -> ISOBook tab -> untick unused documents -> Update.
Duplicate project sites: open existing site, change (e.g. name), click 'Duplicate Project Site' (copies all settings incl. document settings and ISOBook configs), close with Cancel.
