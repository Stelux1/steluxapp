# 5.35 NDT Archive
URL: https://websonik.com/kennisbank/5-35-ndt-archive/ — Updated 30-08-2024
Quick place to look up a report number. Overviews: **Finished NDT** (results processed); **Open NDT results** (NDT performed but result not yet received/processed); **Open NDT welds** (welds flagged as needing NDT but no request made yet). One screenshot (2024-08-30 11.41.45): the archive screen with these three views.

## Screenshot findings (from screenshot)
Page "Finished NDT": buttons Refresh, Export, Filter and a view dropdown ("Switch view") with the three views Finished NDT / Open NDT results / Open NDT welds. Finished NDT columns: Project, ISO No, WN, Type, Welder, Dia (inch), Date, NDT process (e.g. "1/RT-EN-ISO-17636-1 Class B (SGS)"), Result (Accepted / Rejected / N/A), Ide 1, Chg.No. 1, Material 1, Ide 2, Chg.No. 2, Material 2, WPS, Beg. (?) and Rep. No. (report number e.g. "4474820"), Open (link).
