# 5.13.01 Introduction (WPS Designer)
URL: https://websonik.com/kennisbank/5-13-01-introduction/ — Updated 22-06-2026
WPS Designer = WeldPilot module to create, review, approve, maintain WPS; replaces spreadsheets/legacy entry with structured editor, digital approval signatures, PDF generation, audit trail.
Supports: project-specific WPS; company-wide master templates copied to projects; pre-fill from PQR records or saved templates; multi-step approval with digital signatures; official signed PDF linked to the project WPS register.
Key functions: WPS lifecycle **Draft -> Review -> Approved -> (Superseded / Archived)**; multi-tab editor with tabs **General, Material, Technique, Consumables, Parameters, Groove, Links, Approvals, History**; Source data = central management of dropdown values (materials, processes, positions...); compatibility rules = automatic filtering of valid combinations in editor; master templates = approved company WPS marked master, project copies via "Use for project"; digital signatures = canvas or stored signature per approval step; audit trail = all changes logged on History tab.
Roles: Welding engineer/preparer (create/edit draft, link PQRs, submit review); QA/QC reviewer (review, sign steps, final approve); Project engineer (request project copies from master templates); Administrator (profiles/permissions, source data, compatibility rules); Read-only user (view approved WPS, export PDF when permitted).
