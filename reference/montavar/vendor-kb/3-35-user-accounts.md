# 3.35 User accounts
URL: https://websonik.com/kennisbank/3-35-user-accounts/
Last updated 12-06-2026

## Text
- New user: button "Voeg gebruiker toe" (Add user). In the new window assign the needed rights per project, click "Voeg toe" (Add). A user can get specific rights per project (several profiles). A colleague who temporarily works elsewhere need not be deleted: deactivate and re-activate later.
