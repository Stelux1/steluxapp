# 5.44 Test systems
URL: https://websonik.com/kennisbank/5-44-test-systems/ — Updated 12-06-2026
Test systems are composed at **spool level**: e.g. in a workshop many flanged spools from different isometrics can be tested together if test conditions are met. Spools not tested (open ends) can be assigned to a system that is not tested: tick **'Testing not applicable'** while creating the system.
Colours: **blue = not tested; green = test is ready (done); white = test not ready**.
Add documents to a test system: click its name, add documents under the right label, 'Save'. To delete a document tick it and 'Save'. Screenshots: Afbeelding148, 2024-08-30 12.53.14 (list with colours).
