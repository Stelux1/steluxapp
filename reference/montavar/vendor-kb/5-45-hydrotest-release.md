# 5.45 Hydrotest release
URL: https://websonik.com/kennisbank/5-45-hydrotest-release/ — Updated 12-06-2026
Set up a test system: tick spools, move them to the desired test system via **'Verplaats'** (Move). Print a test folder: click 'Hydrotest release', fill needed fields, tick attachments, 'Confirm' (generation can take time). Sign-off after test is done, approved and acceptance documents signed: click 'Results', select the **PTC**, select the acceptance document, 'Add'. Menu 'Results History' shows all test results and status of uploaded documents. Screenshots: Afbeelding151, 152 (dialogs).
