# 5.13.05 WPS Editor
URL: https://websonik.com/kennisbank/5-13-05-wps-editor/ — Updated 22-06-2026
Nine tabs. Locking: Approved/Superseded/Archived = read-only (use Create Revision). Review (after first signature) = content locked until all steps signed; editing invalidates signatures.
Tabs: General (identification, norm, dates, master flag); Material (base materials, thickness ranges, groups); Technique (processes, positions, joint types, heat treatment); Consumables (filler wire, flux, gas, tungsten); Parameters (amperage, voltage, travel speed etc. per pass); Groove Design (groove type, angles, root gap); Links & PQRs (linked PQR and supporting documents; "Link document" modal); Approvals (signatory steps, digital signatures; in draft: define steps - manufacturer, customer, third party - before submit); History (chronological audit: creation, field changes, status transitions, signature events).
General tab fields: WPS Number (fixed after creation), Revision, WPS Short Number (opt), Project (req), Norm e.g. ASME IX, EN ISO 15614 (req), WPS Date (req), Language = PDF/output language (req), Product Type Pipe/Plate/Both (req), Prepared By (opt), Master template checkbox (when checked on an approved WPS it becomes eligible for Use for project), Notes.
Material tab dropdowns come from Source Data -> Materials; compatibility rules may restrict choices. Technique: welding process(es), positions, joint types, preheat, interpass, PWHT requirements. Consumables: filler materials, shielding gas, backing gas, tungsten types from source data. Parameters per pass/run: current, voltage, travel speed, wire feed.
Review status: content-lock banner appears after the first signature. Actions dropdown: Save Draft (not available when locked); Submit for Review (draft -> review, requires validation); Final Approve WPS (when all steps signed); PDF Export (preview/download templates). Also in Actions: clone, save as template, revision, archive.
Approved: green Approved badge, yellow Locked banner (read-only; create revision); Actions -> PDF Export; View PDF from list. Top bar: Saved indicator (auto-save status), Actions, Back to List.
