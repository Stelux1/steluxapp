# 3.04 Project Site archiveren (archive a project site)
URL: https://websonik.com/kennisbank/3-1-3-project-site-archiveren/
Posted 11-09-2022, last updated 15-01-2025

## Text
- A completed project can be archived. The option is in the "Bewerken" (Edit) menu of a project: tick "Archived". Archived projects stay available (open them with "Show archived sites") but disappear from the list of running projects.
