# 5.32 Options menu
URL: https://websonik.com/kennisbank/5-32-options-menu/ — Updated 30-08-2024
'+ Add weld'. Next to each weld a menu: 'Las bewerken' (edit), 'Las verwijderen' (delete), 'Her-waarmerk registratie' (re-stamp / re-certification registration). Edit = pencil icon; there you also indicate if a weld needs NDT. Delete = trash icon. Re-stamp = stamp icon, choose in menu who performed it. Checkboxes beside 'Options' column give mass edit (see 5.301). Screenshots: weld list with icons; edit form (2024-08-30 11.24.34).

## Screenshot findings (from screenshot)
- Per-weld Options column icons: pencil (edit), trash (delete), and a check-in-circle icon (this is the "Her-waarmerk registratie" / re-stamp or weld-completion action; shown green when set). At the right of the Options column a checkbox per weld; the column header has a select-all checkbox (pink/ticked in screenshot). When boxes are ticked a button **"Mass edit welds"** appears in the top bar (beside Options and + Add weld).
- Weld table columns visible: WPS, D (diameter e.g. 42", 44"), S (spool letter A/B/C or "-"), Options. Status block: "86.8%" with "Field not ready" and green "Prefab completed"; "Hydrotest completed: --- | PTC 129"; "Punch / PrePunch: No | No".
