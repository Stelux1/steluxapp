# 3.24 Pick List archive
URL: https://websonik.com/kennisbank/3-24-pick-list-archive/
Last updated 12-06-2026

## Text
- After clicking the "Start" button (isometric execution) a pick list (PDF) is created and stored. It can be used to lay out or fetch materials for further processing.
- The printer icon opens the earlier created pick list (PDF). The button next to the printer shows a list of materials; there you register whether the materials were picked up and by whom, and you can add more info.
