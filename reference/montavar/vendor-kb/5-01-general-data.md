# 5.01 General data
URL: https://websonik.com/kennisbank/5-01-general-data/ — Updated 26-08-2024

In WeldPilot you can add projects and switch between projects. Only projects you have rights for are visible. An administrator can: delete a project, create a new project, set up a project including milestones for work preparation and execution, archive a project.
