# 5.13.14 FAQ
URL: https://websonik.com/kennisbank/5-13-14-faq/ — Updated 22-06-2026
Q/A summary: menu item missing -> module disabled in System settings or profile lacks Show (s). Clone = independent draft copy; Use for project = copies approved master to a target project and tracks master as source. Approved WPS cannot be edited -> create Revision; old revision Superseded. Delete: Delete (d) right and only Draft. New process: Source Data -> Weld Processes -> Add. Change after signature invalidates signatures. Official PDF: View PDF on list or PDF Export (regenerate after re-signing). One WPS record belongs to one project; use Use for project for copies. Compatibility rules = business rules hiding/warning invalid combos (process vs material). Template: Actions -> Save as Template (Edit right).
