# 3.36 Profiles
URL: https://websonik.com/kennisbank/3-36-profiles/
Last updated 12-06-2026

## Text
- New profile: give it a name and optionally a description, tick the wanted rights, click "Opslaan" (Save); then assign it to a user. To change an existing profile click "Bewerken" (Edit), set the ticks, "Opslaan". After a browser refresh the new rights are immediately visible to the user.
