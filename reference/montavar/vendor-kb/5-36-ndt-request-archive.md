# 5.36 NDT Request Archive
URL: https://websonik.com/kennisbank/5-36-ndt-request-archive/ — Updated 26-08-2024
Where created NDT requests are stored: look up a request, see status, print individually or by mass edit. NDT requests still pending or with incomplete data cannot be printed. Screenshots (3): the archive list and print selection.

## Screenshot findings (from screenshot)
The same area is also reached as "NDT requests manager / NDT PRE": page header "NDT requests manager" with tabs **NDT Pre** and **NDT**; top right button "Generate Mass NDT request PRE" (mass request); Search; columns Project, ISO, Weld no., Type, Welder, NDT Pre (red "Yes" + printer icon = request can be generated), Ide.No., Chg.No., Material (1), Ind.No., Chg.No., Material (2), Proces, WPS; a select-all checkbox at far right and per-row checkbox (red = selected for mass request).
