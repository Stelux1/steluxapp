# 5.30 Menu Add Weld
URL: https://websonik.com/kennisbank/5-30-menu-add-weld/ — Updated 12-06-2026
'Add Weld' adds one or more welds to an isometric. To create welds for later editing you must fill at least **four fields: weld number, weld type, spool, diameter**.
Spools as separate entries: if a spool (A, B, C...) is linked to a weld and the weld is deleted, the spool may vanish (if it was routed for services or booked on a laydown). So create a record per spool: Add weld, enter code "SP01" in 'Lasnummer' (weld number) field, choose diameter, select 'Spoel A' (Spool A), repeat for other spools.
