## Text
- Two ways to view isometrics: via an operational system (chapters 3.5, 3.5.1) or directly via the menu "Isometrics" (all isometrics regardless of system; use Filter and quick filter; the current status of an isometric can be read there).
- "Options" menu actions: **Delete all isometrics** (careful; only for application administrators); **Delete selected isometrics** (after selecting some); **Edit Isometrics (Mass Edit)** - select several isos, open, fill the fields to change/complete, "Update" (handy when importing isos without all info); **Set Phase (Mass)** - give several isos a progress phase at once; as work preparer you use it to mark that you have pulled materials (uitgetrokken) for a set of isos: select the isos, click the option, switch on the first option, "Update"; **Generate ISO Book** - create work folders for isos. (Chapter references "XXXX" left unfinished in the article.)
- Indicator columns (X = no, check = yes):
  - NoBo: X no Notified body line (Iso) / check Notified body line
  - PWHT: X no PWHT line / check PWHT line
  - M (MTOPilot): X no materials yet / check materials present
  - E (ESTPilot): X no calculation yet / check calculation present
  - W (WeldPilot): X no welds yet / check welds present
  - Pfb (Prefab): X prefab not ready / X prefab ready not signed off / check prefab ready and signed off
  - Fld (Field): X field not ready / X field ready not signed off / check field ready and signed off
  - Doc. (Iso): X no ISO present / check ISO present
  - If no indicator shows in Pfb and Fld, there are no welds (not created or no welding work).
- Data refreshed automatically every morning; "Laatst refresh" (last refresh) date/time shows when; click "Vernieuwen" (Refresh) for a current view; refreshing is immediately visible to all users.
