# 5.29 Open isometric
URL: https://websonik.com/kennisbank/5-29-open-isometric/ — Updated 12-06-2026
Open via operational system or menu 'Isometric List'. Legend same as MTOPilot (chapter 3.22).
Menu Options: 'Add attachment' (select document label, select file, 'Upload'). 'Attachments' menu: open, print, delete, download; tick and 'Delete'.
If you use a visual inspection report (Vi) on the weld seam before welding: enter results via **'Set Vi results on multiple welds'**: choose document number, tick inspected seams, choose file, 'Uploaden'. Menu 'Visual reports archive': overview of uploaded Vi docs + blank PDF to print.
'Generate mass NDT request' = NDT request for multiple welds in an isometric; the option 'NDT req.' must be ticked on those welds first. 'Generate mass PWHT request' works the same way.
Upload results on several welds: 'Upload NDT on multiple welds PRE', 'Upload NDT on multiple welds', 'Upload PWHT on multiple welds': tick welds, fill report numbers for up to **4 examinations**, 'Accept', choose reports, 'Upload'.
'Punchlist' menu: shows only open punch items of this isometric; add items, change status, delete; the other two tabs show the general status of all punch items incl. passed pre-punch and punch items.
'Set phase' menu: manage work-preparation status per isometric; indicate which parts (KPIs) are ready for preparing a work folder.
Since 28-09-2022: edit the isometric legend from the isometric: pen icon next to Options menu.
Update 25-10-2022: overview of deleted welds; app administrators (highest rights) can open Options -> 'Show deleted welds' then button 'Reset' under label Options to restore.
Update 05-03-2026: manual weld ordering: Options -> tick **Enable welds sorting** -> up/down arrows next to welds; move; stays on to keep custom order; off = default automatic order; setting per isometric. Reason: several systems connecting to one header give illogical default numbering (order of connection).
