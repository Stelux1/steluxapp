# 3.23 Isometric execution
URL: https://websonik.com/kennisbank/3-23-isometric-execution/
Last updated 02-09-2024

## Text
- When all required materials for a given phase or label (Prefab, Field, Supports, etc.) are present - **from 70 % completeness** - a start button appears behind an isometric.
- Example: two isometrics need the same materials but stock suffices to start only one with prefab. Both show a "Start" button; once you start one (click "Start"), the button disappears at the other, because there is not enough stock for the second.
- To first look at what you can start by priority: click "Reserve" first. This reserves materials for that isometric; you can step back and undo the reservation. After "Start" is clicked this step cannot be reversed, unless you perform various manual actions per item to restore it.
- Not stated in this article: the names BLOCKED / PARTIAL / STARTABLE / STARTED, the Type filter (Shop/Field/Valves) as such, the formula of the percentage.
