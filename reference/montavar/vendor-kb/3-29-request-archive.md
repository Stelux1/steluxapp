# 3.29 Request archive
URL: https://websonik.com/kennisbank/3-29-request-archive/
Last updated 03-09-2024

## Text
- Archive of material and spool requests. To make and record a take-off (afname) of services you can also print the "Release document" via the second printer icon. With the button "Uploaden" (Upload) you can upload an approved (geaccordeerd) document.
