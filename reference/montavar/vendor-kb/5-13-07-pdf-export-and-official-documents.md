# 5.13.07 PDF Export and Official Documents
URL: https://websonik.com/kennisbank/5-13-07-pdf-export-and-official-documents/ — Updated 22-06-2026
Actions -> PDF Export: Preview (in browser) or Download. Several PDF templates may appear; * marks auto-selected template based on norm/language. After final approval the system generates an official PDF with signatures: View PDF on list (approved rows), Actions -> PDF Export in editor, Regenerate PDF (Export right) if signatures updated. Official document linked to the legacy WPS register (wps_method_id) for project use.
