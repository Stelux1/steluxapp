# 5.13.02 Getting Started (WPS Designer)
URL: https://websonik.com/kennisbank/5-13-02-getting-started/ — Updated 22-06-2026
Menu path: left nav -> **Weld data -> WPS Designer** (screenshot 1: menu with that item). Needs system setting "Enable WPS Designer"; if menu item greyed out, ask admin.
Areas: WPS list (main page: overview, filters, create button); Source Data (button on list page, embedded panel for master data); WPS Editor (Edit/View on a row, multi-tab); Profiles (System -> Profiles, permissions).
Six permission flags on the user profile (letter): Show (s) open + view; Insert (i) create WPS, clone, revision, use master for project; Edit (e) edit drafts, submit for review, archive; Delete (d) delete draft WPS only; Approve (m) submit for review, sign, final approve; Export (x) preview/download PDF, view official PDF. Administrators (role 1) have all rights automatically. Screenshot 2: the profile edit screen with WPS rights.
First-login checklist: see the menu item; your project in the Project filter; Insert enabled if you create; Approve and Export enabled if you approve.
