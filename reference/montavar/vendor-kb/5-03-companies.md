# 5.03 Companies
URL: https://websonik.com/kennisbank/5-03-companies/ — Updated 12-06-2026
Enter company name, click 'Voeg toe' (Add); optional description. Workshops (werkplaatsen): 'Voeg werkplaats toe' (Add workshop), name + Add, optional description. Companies and workshops can be edited/deleted via edit and delete icons. Once created, assign them to welders in tab 'Lassers' (Welders) by selecting company/workshop at the welder, so welder performance per company/workshop can be seen. One screenshot (Afbeelding92): the companies/workshops screen.
