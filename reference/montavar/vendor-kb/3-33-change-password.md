# 3.33 Change password
URL: https://websonik.com/kennisbank/3-33-change-password/
Last updated 06-01-2023

## Text
- After receiving a login name and password from an application administrator, it is recommended to create a new password. Choose a strong password with upper and lower case letters, digits and symbols. The application recognises weak passwords and warns with a red banner.
