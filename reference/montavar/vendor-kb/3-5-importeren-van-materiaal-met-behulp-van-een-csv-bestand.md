# 3.06 Importeren van materiaal met behulp van een CSV bestand (import material with a CSV file)
URL: https://websonik.com/kennisbank/3-5-importeren-van-materiaal-met-behulp-van-een-csv-bestand/
Posted 11-09-2022, last updated 12-06-2026

## Text
- The material library is a key part of MTOPilot. Use the same codes as in the piping specifications to identify materials.
- Four ways to fill the library: take over an existing project; import data completely new; link material records from other projects; add a single new item.
- Steps: download the CSV import template and open it in Excel; enter materials per the template; save and import into MTOPilot; check that all were added and no mistakes made; fix or delete wrong materials; save the material library.
- Before importing, follow all steps of chapter 1.2 (preparing the CSV; articles 1-1/1-2, other agent's scope) to avoid incomplete or wrong import.
- To import: select the CSV file; click "Import"; be patient (can take minutes, because the application compares with earlier imported data); check; fix/delete; save.
- The article does NOT list the columns of the sheet in text.
- Tags: csv, import, importeren, materiaal, voorbereiden.
