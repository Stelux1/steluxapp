# 5.04 Attachment names
URL: https://websonik.com/kennisbank/5-04-attachment-names/ — Updated 12-06-2026
Add a document to an isometric: click 'Add attachment', choose the label (attachment name) it belongs to, 'Bladeren' (Browse) to pick file, 'Opslaan' (Save). A document can be added to several isometrics at once by selecting several isometrics in the dropdown. View: click the isometric in the list, then 'Attachments' (view/delete). 'Export' exports to PDF or printable version; choose to export only documents for the isometric work package or for both work packages (prefab and field); can also export in document order as set in the 'Sorting' section; then click 'Exporteren'.
