# 5.13.11 Common Workflows
URL: https://websonik.com/kennisbank/5-13-11-common-workflows/ — Updated 22-06-2026
11.1 New WPS from scratch: Create New WPS, project + number, complete tabs, link PQRs, define approval steps, Submit for Review, signatories sign, Final Approve, download official PDF via View PDF. 11.2 Deploy master: master Approved with Master template checked; Use for project; target project -> Projectkopie maken; adjust; review/approve for that project. 11.3 Revise approved: Actions -> Create Revision; edit new draft; submit, sign, approve; previous revision becomes Superseded upon approval of the new one. 11.4 Clone as Draft: on any non-archived WPS; enter new WPS number; independent copy. 11.5 Archive: approved WPS -> Actions -> Archive WPS; read-only archived.
