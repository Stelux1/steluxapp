# 3.14 Order materials
URL: https://websonik.com/kennisbank/3-14-order-materials/
Last updated 02-09-2024

## Text
- After materials have been selected for one or more isometric drawings (MTO), they can be merged here by similarity (samenvoegen op soortgelijkheid). Saw loss (zaagverlies) for oversize must be determined by the user yourself - the application does not add an allowance.
- Use the quick filter to find the wanted materials, select (check) the needed ones, then click "Order checked materials" to create a PDF document. The PDF can be used to request a price (quotation) and also to order materials.
- Linking a supplier to the order is done in the "Order archive" section (see 3-19), not here. That lets you track which materials were delivered by which supplier and if they meet spec.
