# 3.01 General data
URL: https://websonik.com/kennisbank/3-1-general-data/
Posted 11-09-2022, last updated 12-06-2026

## Text
- In the application you can add projects and switch between projects. Only projects for which the user has the right permissions are visible.
- An administrator has all rights to: create a new project; set up (inrichten) a project including milestones for work preparation (werkvoorbereiding) and execution; archive a project; delete a project.
- Tags: project, project site.
