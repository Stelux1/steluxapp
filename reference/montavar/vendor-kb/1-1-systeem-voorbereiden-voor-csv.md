# 1.01 Systeem voorbereiden voor CSV (Prepare the system for CSV)
URL: https://websonik.com/kennisbank/1-1-systeem-voorbereiden-voor-csv/ — Last updated 12-06-2026 (posted 09-09-2022)

Purpose: to start quickly with Websonik apps, import as much data as possible by CSV. For Excel to show CSV files correctly in columns, Windows regional settings must be adjusted; skip if CSV already displays correctly.

Steps (Windows): Settings => Time and language => Region (Land/regio) => Additional date, time and regional settings => "Change date, time or number formats" => "More settings" (Meer instellingen). Set **Decimal symbol = `,`** and **List separator (Lijnscheidingsteken) = `;`**. Click Apply and OK. Afterwards CSV opens as rows/columns in Excel. Ignore Excel's warning and continue editing the import data.
So: the import CSVs are semicolon-separated with decimal comma (European format).
