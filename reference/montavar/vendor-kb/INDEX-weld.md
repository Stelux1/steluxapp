## Answers found

1. Tracer welds after a rejected NDT result — not in the knowledge base as a rule (how many, same welder/WPS, automatic vs manual). Only traces: a checkbox **Tracer** on the Add weld / Edit weld / Mass edit welds dialogs (5-30-menu-add-weld, 5-30-1-mass-edit-welds, 5-23-ndt-process, 5-34-pre-ht-pwht-request-manager, 5-02-project-sites) and the dashboard report **"Welder tracking - With tracer"** (5-05-dashboard). Also a checkbox **Repair**. Status: partly (existence of the flag/report only).

2. Prefab/Field release — 5-40-prefab-release: press "Prefab complete" only after all NDT is performed and results processed, after all prefab welds are done and the prefab release indicator has appeared; release note: filter on ITP, Go, tick isometrics, "Release selected"; signed copy via Options -> "Upload signed docs"; "Release archive" holds unsigned and signed (printer icon = signed uploaded). 5-41-field-release: works the same; align Field release 1:1 with the isometrics of a test system; a signed Field release is the release for the strength test. Weld screen shows "Prefab complete / Field not ready / Field complete" badges (5-40, 5-29). What **Reopen** does and when a weld is **locked (padlock)**: not in the knowledge base. Status: partly.

3. Mandatory fields / welder-WPS — 5-02-project-sites (screenshot text): with project option "Mandatory fields", when a weld record is added/edited **and a welder is entered**, required: Weld Type, WPS Number, Weld Date, Diameter, Charge Number 1 / Charge Number 2. Certificates: Charge Number, Diameter, Material Part, Type of Material, Schedule, Wall Thickness, Certificate Type (also 5-20-1-material-certificates). Minimum to create a weld for later editing: weld number, weld type, spool, diameter (5-30-menu-add-weld). "Validation on WPS": a welder can only be assigned if the welder's qualification matches the weld's WPS (5-02-project-sites); one qualification can list several WPS (5-08-welder). Answered.

4. Punch types A/B/C/D and which release they block — 5-46-punch-list and 5-29-open-isometric only show pre-punch vs punch, a Type dropdown ("A - Prio 1" visible), types A/B/C appearing as column values, and open/finished/passed/removed statuses. Which type blocks which release: not in the knowledge base. Status: not found (partial UI only).

5. Signature rules — Visual inspection report full vs short signature: not in the knowledge base. Found: LISL option "Signature on each page" (5-31-reports-menu) and an ISO-book "LISL with Signatures" option; project Document settings let you rename the signature labels of the Pressure Test Plan (Subcontractor QA/QC, Subcontractor Construction, Principal UI, Contractor QA/QC, Contractor Construction, NoBo) (5-02-project-sites); Field/Prefab release notes carry three signature boxes (5-40); WPS approval uses digital signatures with steps Manufacturer/Customer/Third party and signature invalidation on edit (5-13-06-approval-workflow-and-signatures). Status: partly.

6. LISL variants — 5-31-reports-menu (text + screenshots): LISL Report (modern/classic, with or without NDT/PWHT columns = two blank charge-number boxes for the workshop), LISL Report [GU], LISL Report (A3), Blank LISL template, "LISL with Signatures", LISL (MV), LISL (GU rev2), LISL V2 (project ISO-book tab in 5-27-projects); light-grey marking of fields to be approved by inspection (A4 and A3); option Prefab / Field / both; 5-02-project-sites sets default doc/rev/procedure numbers for LISL (GU) and LISL (MV). Variants [ISS], [WQ], [WQ ver 2], [GU Rev 3] are not mentioned anywhere; what differs between variants is not explained beyond this. Status: partly.

7. Daily reporting — 5-07-daily-reporting: Daily reporting page, add report (default "All reports"), e-mail, hour/minute, weekday checkboxes (all ticked default); sends progress of welds made and inch-diameter; PDF "Daily report" with weld rows and summary per material group (No, Diameter (Inch)). Answered.

8. ITPs / dashboard KPIs — ITP No and ITP No 2 are isometric fields (5-28, 5-29), ITP filter on the dashboard and Prefab release (5-05, 5-40), ITP document upload via isometric mass edit. ITP templates, ITP/KNR percentage and inspection compliance: not in the knowledge base. Dashboard KPIs (5-05-dashboard, screenshots): "Examined / Total weld length", "Repaired / Total weld length", "Repaired / Examined" pies plus cards Total weld length, Examined, Repaired (in mm) and "Weld types ratio"; no written formulas, "repair performance" not named. Status: partly.

9. Isometrics list flags — 5-28-isometrics-list: NoBo, PWHT, M (materials), E (calculation), W (welds), Pfb (prefab: not ready / ready not signed off / ready and signed off), Fld (same), Doc. (ISO present), blank Pfb/Fld = no welds; data refreshed every morning, "Laatst refresh", Refresh button; colours: orange X = ready not signed off, red X = not ready (screenshot). KPI cards on that list: none described; the waterfall (5-06-overview-iso) lists phase columns and the Set phase checkboxes (5-28, 5-29). Answered for flags; KPI cards not found.

Pre, NDT Req., PWHT Req., Repair, Tracer (and Pre-HT in newer version), NDT location Pre + 4 NDT processes, NDT location + 4 NDT processes (answered). Export weld data — 5-39-export-weld-data: all weld data, per project or all sites, "Download CSV" (text says Excel), may take many minutes; no column list (partly). Assign Iso to FWP — 5-43-assign-iso-to-fwp and 5-42-field-work-packages (answered). Hydrotest release and test systems — 5-44-test-systems, 5-45-hydrotest-release (answered incl. dialog fields, colours blue/green/white). Flange management: not found (only the attachment type "Flange tightening" in 5-04/5-29). Status: partly overall.

Status: not found.

Users, profiles, rights — 2-1-functie-profiel-aanmaken, 2-2-aanmaken-van-een-applicatiegebruiker, 5-47-system, 5-13-02-getting-started: profiles per application with 7 permission columns per screen; per user and per application a tab with Enabled, Access (specific project sites or all) and a profile per project site; user list shows On/Off per application (MTOPilot, ESTPilot, WeldPilot, TeamPilot, ToolPilot); sample profiles; WPS Designer flags s/i/e/d/m/x; 2FA only by Websonik admin; Company data editable only by Websonik admin. Answered.
