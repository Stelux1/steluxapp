# 5.06 Overview – Iso
URL: https://websonik.com/kennisbank/5-06-overview-iso/ — Updated 12-06-2026
'Watervaloverzicht' (waterfall overview) showing the statuses an isometric can be in. Each work preparer (werkvoorbereider) changes the isometric status when they complete a task; gives a current picture of work preparation to do and priorities. Only one image (Afbeelding96) = the waterfall chart; no field details in text.

## Screenshot findings (from screenshot)
Page "Overview - Iso" (waterfall): a filter dropdown at top right ("ALL"); eight columns side by side, each with a header, a count badge ("Found N isometrics") and a vertical list of isometric numbers (links): **No status set**, **Materials (MTOP)**, **Estimate (ESTP)**, **Welds defined (WP)**, **Isometric formatted**, **Field documentation**, **Test documentation**, **Release documentation**, **Work preparation 100%**. (Nine columns.) These are the same phases as the Set phase checkboxes; an isometric appears in the column of its latest phase.
