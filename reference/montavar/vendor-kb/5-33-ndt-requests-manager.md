# 5.33 NDT Requests Manager
URL: https://websonik.com/kennisbank/5-33-ndt-requests-manager/ — Updated 06-03-2026
Collecting page for all welds in a project that still need NDT (NDO-pre and NDO examinations). Select welds -> 'Generate Mass NT request' (sic).
Multiple NDT per weld: request several NDT examinations for one/several welds (customers need multiple, sometimes by different companies/phases). Steps: decide welds and exams; click printer icon next to the weld (or 'Mass Request'); popup: tick/untick which NDT examinations; 'Go'; repeat per open request.
Update 05-03-2026: option **Single page request** in the popup of 'Generate mass NDT request': puts all selected requests in one consolidated document instead of one page per isometric.
