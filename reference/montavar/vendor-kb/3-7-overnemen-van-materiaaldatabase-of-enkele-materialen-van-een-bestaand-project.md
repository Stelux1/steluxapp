# 3.07 Overnemen van materiaaldatabase of enkele materialen van een bestaand project (take over material database or single materials from an existing project)
URL: https://websonik.com/kennisbank/3-7-overnemen-van-materiaaldatabase-of-enkele-materialen-van-een-bestaand-project/
Last updated 12-06-2026

## Text
- To take over the whole material library of an existing project: follow chapter 3.1.2 (= article 3-1-2 "Materiaalbibliotheek in menu Project Sites": "Import materials from" dropdown / import from another project site).
- To make one material line available in another project without creating a new item: go to the material library of the project where the item exists; open the item in edit mode; select the project where the item is needed; click "Update".
