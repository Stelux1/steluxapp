# 3.20 Certifications
URL: https://websonik.com/kennisbank/3-20-certifications/
Last updated 27-08-2024

## Text
- Section to process and manage material certificates; important to know where each material component was used (project, isometric and weld level).
- Add: button "Add certification"; enter all needed data and select a PDF (the certificate). Uploading the PDF immediately is not mandatory - do it later through "Bewerk invoer" (edit entry).
- Import many certificates by CSV: button "Import certifications"; download the import file there and prepare it (per chapter 1.2). After the import, each PDF must still be uploaded through "Bewerk invoer".
- Trace usage: icon next to "Bewerk" (three-rows icon) shows in which projects, isometrics and weld numbers the material was used.
- Export: button "Export to ZIP" top right exports the certificates.
- A document icon next to the index number means a certificate PDF is uploaded; click to view.
- Edit: pencil icon in the "Opties" (Options) column on the right.
- "Filter" button searches certificates within existing projects.
