# 3.19 Order archive
URL: https://websonik.com/kennisbank/3-19-order-archive/
Last updated 02-09-2024

## Text
- Holds all created PDF orders. Change the date range to show orders between two dates. Here you link suppliers to orders, print orders, or view the content of a list.

## Screenshot (from screenshot)
- Page "Order archive" with a left filter column: Project (dropdown "All projects"), From date (e.g. 03.08.2020), To Date (e.g. 30.09.2024), button "Filter". Right: sort dropdown "Order by date desc.", page size, search. Columns: Date (date and time), Request number (5-digit, e.g. 00001..00007), Assigned supplier (e.g. Arcus, ERIKS, Reehorst, or "NA" = not assigned), Options: three icon buttons (paperclip-like = assign supplier/attachment, printer, list = view contents). Request numbers are not strictly in date order (00003 dated 05.08.2022 appears late in list sorted desc), i.e. number follows creation order.
