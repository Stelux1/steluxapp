# 3.02 Project sites
URL: https://websonik.com/kennisbank/3-1-1-project-sites/
Posted 11-09-2022, last updated 15-01-2025

Note at top: corresponds to "4.01 Het aanmaken van een project" (ESTPilot) and "5.02 Project sites" (WeldPilot).

## Text
- A project can be a stand-alone project but also a collection of small projects or repairs at a fixed location.
- To add a project: click "Add project site" and fill in the fields.

### Project settings (tab)
1. **Mandatory fields** setting:
   - when creating a weld record: Weld type, WPS number, Weld date, Diameter and Charge number are required;
   - for material certificate records: Material type, Schedule and Certificate type are marked as essential.
   - Not-filled required fields get a red marking.
2. **Validation on WPS**: a welder can only be assigned to a weld record if their qualification matches the required WPS (all required data must be complete/correct for this to work).
3. **Archived**: archiving keeps the active list tidy; archived projects are reachable through the button "Show Archived Sites" and are easily restored.
4. **Material management display setting** (toggle for indicator in isometrics): when ticked, the indicator lights up as soon as materials have been added to an isometric. When not ticked, the indicator lights up when a pick list has been created.

### Document settings (tab)
Company-standard names/numbers replacing application defaults:
1. Sub-contractor QA/QC, Sub-contractor construction, Main user interface (Hoofdgebruiker interface), Contractor QA/QC, Contractor construction, NoBo: these fill the labels of signature fields on the pressure test plan (Druktestplan).
2. Doc. Nr. & Rev. Nr. and procedure number (VT report): update defaults of the VT report.
3. Doc. Nr. & Rev. Nr. and procedure number (LISL (GU) & LISL (MV) report): same for those reports.
