# 3.03 Materiaalbibliotheek in menu Project Sites (material library in the Project Sites menu)
URL: https://websonik.com/kennisbank/3-1-2-materiaalbibliotheek-in-menu-project-sites/
Posted 11-09-2022, last updated 12-06-2026

## Text
- You can reuse a previously created material library by selecting it in the dropdown "Import materials from" (when creating the project). Importing a library is also possible later.
- To link the material library of another project to a newly created project: click the arrow next to the project (see screenshot), pick one of the available libraries, click Import.
- Tags: import, materiaal, mto, project.

## Screenshots (from screenshot)
1. "Project sites" list; in the Options column the right-most (circle/arrow) icon button is framed in red - this is the entry to the import of a material database.
2. Dialog "Import material database from another project site": a dropdown listing existing project sites (names blurred; e.g. "Test Projects 2019" selected) then Import/Cancel buttons.
