# 5.07 Daily reporting
URL: https://websonik.com/kennisbank/5-07-daily-reporting/ — Updated 12-06-2026
Add an e-mail address in section 'Daily reporting' and set a time: the application sends daily the progress of number of welds made and diameters (inch-dia) to the addressees. Announced: future reports for productivity per work preparer and real-time project progress. Screenshots: Afbeelding97, 98 (settings form with recipients and time — see appended notes).

## Screenshot findings (from screenshot)
- **Daily reporting page** ("Daily reporting"): header text "Add email address that will receive daily reports." Left form: Report (dropdown, value "All reports"), Email address, Time Hour (dropdown, e.g. 12), Time Min (e.g. 00), seven day checkboxes Monday ... Sunday (all ticked by default), button Add. Right table: Email address, Report ("All reports"), Time (e.g. 10:00), Mon Tue Wed Thu Fri Sat Sun (green ticks), Options (delete). So one subscription = report type + recipient + time + weekdays.
- **Daily report PDF** ("Daily-Weld-Report.pdf"): title "Daily report"; Home location, Date; table columns No, Project, ISO No, Drawing no., Type, Weld no., Welder, Dia., Material (two lines), Spool; footer table "SUMMARY": rows per material group (e.g. CS = carbon steel: No 22, Diameter (Inch) 92.00; SS: No 16, 25.00); printed timestamp and page x/y.
