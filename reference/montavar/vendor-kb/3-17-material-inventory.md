# 3.17 Material Inventory
URL: https://websonik.com/kennisbank/3-17-material-inventory/
Last updated 12-06-2026

## Text
- Shows all materials present. All receipts processed via the "Invoeren" (take-in) section are added together and shown here.
- Materials can also be added to inventory directly, manually or via an import file - useful when materials are supplied by the client (opdrachtgever).
- Manual add uses the material library. A non-existing item must first be created in the material library (uniformity, prevents wrong entries).
- Import: prepare the import file per chapter 1.2 and use the template file (downloadable after clicking "Import" when the import window is open). "Material No" is a key (unique) field: during import each Material No is checked against the value in the material library.
- Warning: follow the described steps to avoid import problems.
- NOT in this article: Transfer to project, moving between storehouses, return to inventory, corrections with reasons, transfer orders, QR labels (see index: not in KB).
